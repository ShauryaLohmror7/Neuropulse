# NEUROPULSE frontend

React + TypeScript + Vite, Three.js / React Three Fiber, and Framer Motion.

See the [project README](../README.md) for setup, data attribution, scientific limitations and verification. Run `npm run dev` here with the backend on port 8000. `npm run build` runs TypeScript and the production build; `npm run lint` runs Oxlint.

`public/circuits/` contains prepared real anatomy. There is intentionally no generated-neuron fallback.
