# Neural state modes

**Fresh run** is the default. Each input starts with zero activation and zero refractory state. **Continue sequence** retains the previous event's complete numerical activity and refractory arrays, including below-threshold values, plus source-modality labels. This is dynamical state continuity, not learned biological memory. No synapse weights are modified.

Choose the mode before starting. In a sequence, use **Add next event** or **Let activity settle** after playback. The latter advances the model with no new external stimulus. **Reset sequence**, **New experience**, or switching modes starts again. Sequences contain at most six events; this limit is visible and never silently discards old events. An event uses the same default step count and disclosed input schedule as the standalone simulator, but completes its full duration even after activity drops below threshold. Model time advances only on events, not during wall-clock pauses or replay.

`POST /api/simulate-sequence` accepts an events list (up to six strings, each up to 600 characters), recomputes the prefix from a fresh state and carries full internal arrays across boundaries. The endpoint returns the final event, preceding-event counts and step durations. Empty strings mean no new stimulus. State is request-local, so no shared session or browser can contaminate another user's run. Source graph weights remain immutable. Ordinary `/api/simulate` is unchanged and remains isolated.

The **Across the nervous system** panel uses disjoint official class/superclass groups. All 166,700 annotated neurons are counted exactly once. Kenyon cells, MBONs, DANs and CX have explicit annotation-based groups; unlabeled functions are not guessed. Every group shows its total and current/reached count. These are broad annotation groups, not anatomical ROI boundaries. Quiet groups remain visible. Activation of a memory-related group does not establish memory formation, and dopamine activity does not establish happiness or reward learning.

Checks: splitting a small recurrent graph into successive calls reproduces uninterrupted final activity and refractory state exactly; subthreshold/disconnected cells decay across calls; a full-graph sequence carries activity into a no-input event; independent fresh runs reproduce the same result; group counts match the graph and per-step totals. 55 backend tests and the production frontend build pass. Biological plasticity, calibrated internal drives and comprehensive action prediction are still not implemented.
