# Shader sources and presentation

The interface uses the open-source `@paper-design/shaders-react` package already installed in this project (Apache-2.0; package LICENSE/NOTICE retained).

21st.dev references reviewed:
- Neuro Noise / Sensation: https://21st.dev/community/shaders/neuro-noise-sensation-daf72911-8bd3-441e-b749-5486758942ef
- Grain Gradient: https://21st.dev/community/shaders/grain-gradient-1e7c27b0-5d0b-422e-838a-4e9c996a75f2

These listings identify Paper Shaders as their source. Their generated preset exports were locked; no locked source was copied. This implementation uses Paper's NeuroNoise and GrainGradient components with our own champagne/olive settings.

NeuroNoise decorates the introduction; GrainGradient supplies low-contrast edge light around the viewer. Both are decorative, aria-hidden, pointer-transparent, lazy loaded, pixel-budgeted and paused on hidden tabs. Reduced motion uses static frames.

The loading mark is an indeterminate brand animation while actual data requests run. No fabricated percentage and no mandatory waiting period. Once the scene mounts, normalized existing geodesic attributes reveal source skeleton branches over 2.6 seconds; soma and region surfaces fade in. Source geometry is unchanged. This is not firing, growth, or biological timing. Manual interaction or simulation bypasses the entrance; it does not restart for each experience.
